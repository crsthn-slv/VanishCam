# Security policy

## Supported versions
Only the latest `main` is supported.

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private reporting: **Security → Report a vulnerability** on this repository.
Include steps to reproduce and the macOS version. Expect a reply within about a week.

## Scope
VanishCam runs locally, uses the camera, and writes to the OBS Virtual Camera. It has no network access and no telemetry. Reports about camera access, file handling, or the build/release scripts are in scope.
